# Vabe-кодер — Профессиональная разработка ПО

> Интеллектуальная разработка нового поколения с применением искусственного интеллекта.

![Preview](https://img.shields.io/badge/status-production-success)
![License](https://img.shields.io/badge/license-MIT-blue)

## 🚀 О проекте

**Vabe-кодер** — это веб-платформа для заказа профессиональной разработки программного обеспечения. Проект использует ИИ-генерацию кода и предлагает три тарифных плана для задач любой сложности.

### ⚡ Ключевые возможности

- 🤖 ИИ-генерация production-ready кода на 50+ языках
- ⚡ Скорость разработки: от 2 часов до 3 дней
- 🛡️ Аудит безопасности и автотесты
- 📱 Fullstack-разработка (веб, мобильные, API)
- 🔌 Интеграции с платёжными системами, CRM, мессенджерами
- 🚀 DevOps, CI/CD, контейнеризация и деплой
- 📊 Автоматическая генерация документации

## 💰 Тарифные планы

| Тариф | Стоимость | Срок | Объём кода |
|-------|-----------|------|------------|
| **Базовый** | 5 000 ₽ | 6 часов — 1 день | до 500 строк |
| **Про** ⭐ | 50 000 ₽ | 1 — 2 дня | до 5 000 строк |
| **Элит** 👑 | 500 000 ₽ | 2 — 3 дня | неограниченно |

- Анимированный фон с светящимися линиями (Canvas API)

## 📦 Установка

### Локальный запуск

1. Клонируйте репозиторий:
```bash
git clone https://github.com/ваш-username/vabe-coder.git
cd vabe-coder
```

2. Откройте `index.html` в браузере:
```bash
# Windows
start index.html

# macOS
open index.html

# Linux
xdg-open index.html
```

Или просто перетащите файл `index.html` в окно браузера.

## 🚀 Деплой

### GitHub Pages

1. Перейдите в **Settings → Pages**
2. В разделе **Source** выберите ветку `main` и папку `/ (root)`
3. Нажмите **Save**
4. Ваш сайт будет доступен по адресу:
   `https://ваш-username.github.io/vabe-coder/`

### Netlify (drag & drop)

1. Зарегистрируйтесь на [netlify.com](https://netlify.com)
2. Перетащите папку проекта в область деплоя
3. Сайт будет опубликован мгновенно

### Vercel

```bash
npm i -g vercel
vercel
```
